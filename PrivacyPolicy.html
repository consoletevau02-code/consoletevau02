개인정보처리방침 (Privacy Policy)

최종 수정일: 2026년 9월

1. 개요

본 애플리케이션(WPSOFT Card News Video Automation, 이하 "본 서비스")은 개발자 본인이 자신의 소셜미디어 콘텐츠 제작 및 게시 작업을 자동화하기 위해 제작한 개인용 도구입니다. 본 방침은 본 서비스가 각 소셜미디어 플랫폼(Instagram, TikTok, YouTube, Threads 등)의 API를 사용하는 과정에서 어떤 정보를 다루는지 설명합니다.

2. 수집·처리하는 정보

정보 종류수집 방식 및 목적
플랫폼 액세스 토큰(Access Token) 사용자 본인이 각 플랫폼의 개발자 도구를 통해 직접 발급받아 입력. 콘텐츠 게시 요청을 해당 플랫폼에 대신 전달하는 용도로만 사용됩니다.
플랫폼 사용자 ID / 계정 별칭 사용자가 어느 계정에 게시할지 구분하기 위해 로컬에 저장됩니다.
생성된 콘텐츠(뉴스 요약, 이미지, 영상, 음성) 사용자가 지정한 뉴스 기사 또는 영상 URL을 기반으로 생성되며, 사용자가 게시를 승인한 플랫폼에만 전송됩니다.

3. 정보의 저장 위치

모든 인증 정보와 생성된 콘텐츠는 사용자 본인의 로컬 컴퓨터(서버)에 저장됩니다. 본 서비스는 별도의 원격 서버나 클라우드 데이터베이스를 통해 사용자 정보를 수집·저장하지 않으며, 운영자를 포함한 제3자가 이 정보에 접근할 수 없습니다.

4. 제3자 제공

수집된 정보는 사용자가 명시적으로 연결하고 게시를 요청한 소셜미디어 플랫폼(Instagram, TikTok, YouTube, Threads 등) 외의 어떠한 제3자에게도 제공되지 않습니다. 각 플랫폼으로 전송되는 정보는 해당 플랫폼에 콘텐츠를 게시하는 데 필요한 최소한의 정보(영상/이미지 URL, 캡션 텍스트, 액세스 토큰)로 한정됩니다.

5. 정보의 보유 및 삭제

액세스 토큰 및 계정 정보는 사용자가 직접 등록하거나 삭제하기 전까지 로컬에 보관되며, 사용자는 언제든지 해당 정보를 직접 삭제할 수 있습니다. 각 플랫폼의 액세스 토큰은 각 플랫폼의 정책에 따라 일정 기간(예: 60일) 후 자동으로 만료됩니다.

6. 아동의 개인정보

본 서비스는 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.
